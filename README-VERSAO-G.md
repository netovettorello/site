# Neto Vettorello — Versão G

**Objetivo:** acabamento premium e coerente, com posicionamento internacional aberto.

## Atualizações
- Navegação em cápsula com acabamento de vidro translúcido.
- Botões pill, cartões com cantos suaves e padrão uniforme de interface.
- Uma única família tipográfica (Geist), com escala contida.
- Seção **Artistic Practice / Prática Artística** com texto objetivo.
- Seção **About the Artist / Sobre o artista** com texto de posicionamento internacional em português e inglês.
- Primeira parte da biografia reequilibrada; as pesquisas culturais e conceituais continuam na página Sobre.
- Título **Clients & Collaborations** para as logomarcas.
- Mantidas as galerias, animações, conteúdo, páginas e CMS originais.

## Publicação no Netlify
1. Descompacte o ZIP e copie o conteúdo para a raiz do repositório GitHub (não o próprio ZIP).
2. No GitHub Desktop, faça Commit e Push.
3. Build command: `npm run build`; publish directory: `_site`.

## Arquivos editados
- `src/css/refinement-g.css` (novo)
- `src/_includes/base.njk` (carrega a folha de estilos)
- `src/_includes/pages/home.njk`
