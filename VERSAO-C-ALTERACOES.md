# Versão C — direção de arte editorial premium

Esta edição evolui a versão B sem substituir a arquitetura, conteúdo, painel ou rotas.

## Atualizações
- Hero editorial: tipografia monumental, nova composição e microtipografia.
- Headline autoral editável no CMS.
- Manifesto em tipografia ampliada, com indexação editorial.
- Menu, botões e cartões menos arredondados, mais próximos de uma galeria contemporânea.
- Cards com movimentos de hover discretos e mais espaço para as obras.
- Ajustes para desktop e celular e respeito a preferência de movimento reduzido.

## Antes de publicar
- Validar o texto de abertura e substituir as imagens derivadas do PDF por arquivos originais.
- Inspecionar todas as páginas em mobile e desktop.
- Conferir imagens hospedadas externamente conforme README da versão B.
- Não alterar o domínio antes de validar o preview no Netlify.

## Execução
`npm ci && npm run build` ou `npm start` dentro desta pasta.

Esta é uma primeira evolução visual de código, não uma homologação completa nem uma reconstrução de identidade.
