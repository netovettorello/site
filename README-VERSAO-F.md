# Versão F — Optical Glass

Evolução da versão E inspirada na materialidade/translucidez das interfaces Apple, sem reproduzir o site comercial.

- Navegação de vidro óptico escuro com desfoque, reflexão discreta e borda iluminada.
- Botões com acabamento satinado e estados de interação.
- Hero com texto contido; fotografias preservadas como protagonistas.
- Cartões da galeria com legenda translúcida e reflexo direcional ligado ao cursor.
- Tipografia Geist única, sem mistura de serifas.
- Ajustes mobile e respeito ao recurso de acessibilidade de movimento reduzido.

Stack preservada: Eleventy 11ty, arquivos originais, idioma PT/EN, CMS e Netlify.

Publicação: extraia os arquivos na raiz do repositório, commit e push. Build `npm run build`, publish `_site`.
